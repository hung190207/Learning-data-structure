# Exercise

For each of the following, answer $yes, \ no,$ or $can't \ tell$. Explain your reasoning.

- Is $3^n = O(2^n)$?
- Is $\log(3^n) = O(\log(2^n))$?
- Is $3^n = \Omega(2^n)$?
- is $\log(3^n) = \Omega(\log(2^n))$?


# Solution

The first one is NO. We need to prove $3^n \le c *2^n$, but after divide both side for $2^n$, the formula is ${\frac{3}{2}}^n \le c$ which is not right.


The second one is YES. 
- $\log{3^n} = n \log{3}$.
- $\log{2^n} = n \log{2}$.

We need to prove that $n \log{3} \le c*(n\log{2})$.

Dividing by n then $\log{3} \le c*\log{2}$ which is right.

The third one is YES. By using the same method with the first one.

The fourth one is YES too. By using the same method with the second one.
