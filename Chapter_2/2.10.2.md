# Exercise

What value is returned by the following function? Express your answer as a function of $n$. Give the worst-case running
time using Big Oh notation.

```java
public int pesky(int n) {
    int r = 0;
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= i; j++) {
            for (int k = j; k <= i + j; k++) {
                r += 1;
            }
        }
    }
    return r;
}
```

# Solution

We use the same way on previous exercise. So the function is:

$\sum\limits_{i=1}^{n}\sum\limits_{j=1}^{i}\sum\limits_{k=j}^{i+j}k$

So the time complexity is $O(n^3)$.
