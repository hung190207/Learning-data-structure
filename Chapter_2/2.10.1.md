# Exercise

What value is returned by the following function? Express your answer as a function of $n$. Give the worst-cse running
time using the Big Oh notation.

```java
public int mystery(int n) {
    int r = 0;
    for (int i = 0; i < n; i++) {
        for (int j = i + 1; j <= n; j++) {
            for (int k = 1; k <= j; k++) {
                r += 1;
            }
        }
    }
    return r;
}
```

# Solution

First, we analysis each loop into function that can calculate:

$\sum\limits_{i=1}^{n-1}\sum\limits_{j=i+1}^{n}j$

Then, we can expand the inner sum like $\sum_{j=i+1}^{n}j = (i+1)+(i+2)+...+n$

So if we times it together we will get the value near $\frac{n^3}{6}$

So the worst-case running time is $O(n^3)$.
