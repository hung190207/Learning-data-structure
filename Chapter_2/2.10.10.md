# Exercise

Prove that $n^3 - 3n^2 - n + 1 = \Theta(n^3)$.

# Solution

So we need to prove that
1. $O(n^3) \le c_1 * n^3$ for some $c_1$ and large $n$.
2. $\Omega(n^3) \ge c_2 *n^3$ for some $c_2$ and large $n$.

We will prove the first one the same as 2-7 exercise. We see that with $c_1 = 2 \ and \ n_0 = 0$ we have the upper bound.

For the second one. Let's take $n = 0$ so we prove that it will always $\ge c_2 * n^3$ which is lower bound.

So from 1 and 2 we proved that $n^3 - 3n^2 - n + 1 = \Theta(n^3)$.
