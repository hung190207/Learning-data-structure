# Exercise

True or False?

- Is $2^{n+1} = O(2^n)$?
- Is $2^{2n} = O(2^n)$?

# Solution

The first one is true, and the second one is false.

Let's put $2^{n+1}$ is $f(n)$, $g(n) = 2^n$

Then we need to prove for any constant $c$, there is $2^{n+1} \le c*2^n$.

Then I put $c = 1 \ and \ n_0 = 0$, the formula is not true.

So I put $c = 2 \ and \ n_0 = 0$, we have $2^{n+1} \le 2 * 2^n$.

With $c = 2 \ and \ n_0 = 0$, we proved the formula and which proves $2^{n+1} = O(2^n)$ too.
