# Exercise

Prove that $n^2 = O(2^n)$.

# Solution

We need to prove $n^2 \le c* 2^n$.

So just take $c = 1$ then check the value of $n$:
- n = 1: 1² = 1, 2¹ = 2 (1 ≤ 2) -> true
- n = 2: 2² = 4, 2² = 4  (4 ≤ 4) -> true
- n = 3: 3² = 9, 2³ = 8  (9 > 8) -> false
- n = 4: 4² = 16, 2⁴ = 16  (16 ≤ 16) -> true
- n = 5: 5² = 25, 2⁵ = 32  (25 ≤ 32) -> true
- n = 6: 6² = 36, 2⁶ = 64  (36 ≤ 64) -> true

So for $n \ge 4$ we proved that $n^2 \le 2^n$

Therefore, $n^2 = O(2^n)$ with $n \ge 4$.
