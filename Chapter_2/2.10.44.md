# Exercise

We have 1,000 data items to store on 1,000 nodes. Each node can store copies
of exactly three different items. Propose a replication scheme to minimize data loss
as nodes fail. What is the expected number of data entries that get lost when three
random nodes fail?

# Solution

- Probability it's not on a failed node = $\frac{999}{1000} \times \frac{998}{999} \times \frac{997}{998} = \frac{997}{1000}$
- Probability it is lost = $1 - \frac{997}{1000} = \frac{3}{1000}$

So the expecting number of lost items is $1000 \times \frac{3}{1000} = 3$ items
